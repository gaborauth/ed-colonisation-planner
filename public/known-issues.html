Known issues

Things this planner deliberately gets "wrong," and why — linked from the in-app hover boxes that mention them. See also the project's README for the full feature list.

Suspected game bug

Terraformable's Agriculture strong-link boost isn't applied

The official Update 3 patch notes (and the community-sourced EconomicEffects.ods research sheet) both list a Terraformable body as an Agriculture strong-link boost condition, worth +0.40 — the same magnitude as every other boost/decrease condition in that table.

Real-game testing found no observable effect from this condition on Agriculture's actual value, however. This is suspected to be a bug in the current game build rather than a documentation error, so this planner deliberately does not apply it — every computed Agriculture value (strong-link modifiers, economy ratios, the body hover's "Default economies"/"Strong links" tables) matches what the game actually does today, not what the patch notes say it should do.

If Frontier fixes this in a future update, the boost should be re-added at its three call sites in src/domain/economyOverrides.ts (computeBoostDecrease, computeColonyEconomyBreakdown, computeStrongLinkBreakdown) — search for TERRAFORMABLE_AGRICULTURE_BUG_NOTE.

Best-effort guess

Journal → buildable slot count estimate

No official formula for how a scanned body's attributes map to its buildable orbital/ground slot count has ever been published. The ground-slot half of the heuristic is sourced from community research (CMDR Nyatto, Flynnvali, and others); the orbital-slot half still has no known per-body formula and is a rougher guess. Always sanity-check the pre-filled estimate against your in-game System Map — the System facilities panel's fields stay fully editable, with a "Reset slots to guess" button to reapply the heuristic if you want to start over.

Best-effort guess

Facility → economy-type mapping

Update 3's body-attribute Colony-economy override table is sourced verbatim from official patch notes, but no official mapping from every Hub/Settlement/Installation building to its own economy type was ever published. That mapping is inferred from each building's name; a few buildings are deliberately left unmapped rather than guessed.

Best-effort guess

Strong-link boost/decrease magnitude (±0.40) and the 10% floor

Official patch notes confirm strong-link boosts and decreases exist, but never state a magnitude. The ±0.40-per-condition and 10%-floor numbers used throughout this planner are community-sourced (the EconomicEffects.ods research sheet), cross-validated against several real reported in-game values before landing — close, but not an official Frontier-published number.

Illustrative only

Population growth curve

No official population-growth formula has ever been published. The curve shown in the Population growth panel is a shaped curve invented only to match the patch notes' qualitative "fast, then slowing" description — never treat its numbers as real predictions. The panel itself carries a permanent disclaimer for the same reason.
